# 🎾 SQUASH PORTAL 2026 — Интерактивный портал о сквоше

Добро пожаловать в репозиторий интерактивного веб-ресурса, посвященного сквошу. Проект объединяет в себе подробный свод правил, тактический планшет, энциклопедию оборудования и интерактивные инструменты для игроков любого уровня.

Сайт доступен по адресу: **[sofasquash.ru](https://sofasquash.ru/)**

---

## 💎 Особенности проекта

Интерфейс приложения выполнен в палитре **Obsidian & Gold** (угольно-черный `#0a0a0c` и золотисто-янтарный `#f59e0b`). Проект разработан по принципу Single Page Application (SPA).

### Ключевые интерактивные модули:

- **Интерактивный 3D-корт (`CourtVisualizer`):** Векторная трехмерная проекция корта. Каждый элемент (стены, линии аута, тин, Т-зона) интерактивен. Для упрощения взаимодействия на мобильных экранах тонкие линии снабжены невидимыми увеличенными хитбоксами (`16px`).
- **Тактический 2D-планшет (`TacticsBoard`):** Модуль для разбора геометрии перемещений и траекторий основных ударов (драйв, боуст, кросс, лоб, дроп, киллшот) с плавной векторной анимацией движения двухточечного мяча и умными контекстными подсказками.
- **Энциклопедия ракеток (`/racquets`):** Интерактивный каталог на 120 профессиональных моделей от ведущих брендов (Harrow, Dunlop, Tecnifibre, Head, Karakal, Oliver, Eye Rackets). Поддерживает полноэкранное сравнение до 5 моделей одновременно и детальный просмотр характеристик.
- **Интерактивный Глоссарий (`/glossary`):** Структурированный словарь на 27 сквош-терминов с алфавитным рубрикатором и аккордеон-навигацией.
- **Правило 2.7 (Виджет переподач `ReServe`):** Игровой кликер с сохранением прогресса в `localStorage`, системой наград и интерактивным квизом на знание правил сквоша.
- **PWA и Офлайн-режим:** Полная работоспособность приложения в условиях отсутствия интернета (например, на цокольных этажах сквош-клубов) благодаря кастомному сервис-воркеру (`sw.js`).

## 🛠️ Технический стек и Архитектура

- **Фреймворк:** Next.js (App Router, статический экспорт `output: 'export'`).
- **Язык разработки:** JavaScript (без TypeScript).
- **Стилизация:** Tailwind CSS v4.
- **Оптимизация:** React Compiler для автоматической мемоизации компонентов.
- **Деплой и хостинг:** GitHub Pages с автоматической сборкой через GitHub Actions (`.github/workflows/deploy.yml`).

### Структура проекта:

В проекте реализован принцип разделения ответственности и сплит-рендеринга. Для обеспечения корректного SEO на статических страницах с логикой `'use client'`, код рендеринга вынесен в отдельные файлы `*Client.js`, а файлы `page.js` экспортируют чистые серверные метаданные:

- `/data` — статические массивы данных (ракетки, тактики, термины).
- `/components` — изолированные UI-компоненты (корт, планшет, квиз, карточки ракеток).
- `/app` — роутинг Next.js App Router.
- `/public` — манифест PWA, сервис-воркер и статические ассеты.

## 📝 Стандарты написания кода

1. **Одинарные кавычки:** Используются одинарные кавычки `'` для всех строковых литералов в коде.
2. **Безопасный localStorage:** Все вызовы `localStorage` оборачиваются в блоки `try/catch`, чтобы избежать ошибок в приватных режимах браузеров.
3. **SPA-переходы:** Используется компонент `<Link>` из `next/link` вместо стандартных тегов `<a>` для мгновенных переходов без перезагрузки страниц и мигания темы.
